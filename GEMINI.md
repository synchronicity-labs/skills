# sync. labs

This extension adds the sync. labs skills (lipsync, talking photos, dubbing, dialogue edits, campaign localization, batch lipsync, the sync. API and troubleshooting) and connects the hosted sync. MCP server at `https://mcp.sync.so/mcp`.

- If the sync. tools are missing or signed out, tell the user to run `/mcp auth sync` and sign in with their sync. account in the browser. There is no API key to copy.
- For any sync. request, use the matching skill. The `setup` skill checks the account and gets the user to a first video.
- Quote the cost of every paid action and wait for the user's approval before starting it.
